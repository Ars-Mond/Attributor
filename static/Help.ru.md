# Attributor — Руководство пользователя

Attributor — это настольное приложение для редактирования **XMP/EXIF-метаданных** стоковых фотографий перед их отправкой в агентства, такие как Shutterstock, Adobe Stock, Getty Images и другие. Оно позволяет встраивать заголовок, описание, ключевые слова и категории прямо в файлы изображений без их перекодирования, сохраняя полное качество изображения.

**Поддерживаемые форматы:** JPEG · PNG · WebP

---

## Начало работы

### Открытие папки

Перейдите в **Файл → Открыть папку…** или нажмите значок папки на панели «Иерархия». Attributor сканирует выбранную папку и отображает все поддерживаемые файлы изображений в дереве файлов.

Последняя открытая папка запоминается и автоматически восстанавливается при следующем запуске.

### Выбор файла

Щёлкните любой файл на панели «Иерархия», чтобы открыть его. Изображение появляется на панели **Просмотр**, а его существующие метаданные загружаются в панель **Управление**.

Если в файле есть несохранённые изменения, Attributor предложит **Сохранить**, **Не сохранять** или **Отмена** перед переключением на другой файл.

## Редактирование метаданных

Все поля метаданных находятся на панели **Управление**.

| Поле | Описание |
|-------|-------------|
| **Имя файла** | Основа имени файла (без расширения). Переименование происходит при сохранении. |
| **Заголовок** | Короткий описательный заголовок изображения (хранится как `dc:title`). |
| **Описание** | Подробное описание для поисковых систем и покупателей (`dc:description`). |
| **Ключевые слова** | Теги, описывающие содержимое изображения (`dc:subject`). |
| **Категории** | Категории содержимого (`photoshop:Category`). |
| **Файл релиза** | Имя документа релиза модели/собственности, если применимо. |
| **Редакционное / Контент 18+ / Иллюстрация** | Флаги атрибуции (галочки). |

«Категории», «Файл релиза» и три флага находятся в раскрывающемся блоке **Дополнительно** под ключевыми словами.

**Счётчик слов / символов** рядом с полями «Заголовок» и «Описание» помогает не выходить за пределы лимитов агентств.

**Флаги атрибуции** описывают изображение для стоковых агентств и заполняются автоматически при AI-атрибутации (их также можно переключать вручную):

- **Редакционное** — реальные события/места, видимые логотипы, бренды или узнаваемые люди (в отличие от «чистого» коммерческого контента).
- **Контент 18+** — обнажённость, сексуальные темы или насилие.
- **Иллюстрация** — цифровое или сильно отредактированное изображение (в отличие от обычной фотографии).

«Файл релиза» и три флага не записываются в сам файл изображения — они хранятся только в базе данных метаданных Attributor (см. **Сохранение и хранилище метаданных**).

### Сохранение и хранилище метаданных

Attributor хранит локальную **базу данных метаданных** как рабочую копию метаданных каждого фото. Она защищает ваши правки (и результаты AI-атрибутации) и позволяет мгновенно открыть фото повторно, не перечитывая файл.

- **Правка** поля или запуск **AI-атрибутации** сразу сохраняются в базу данных, **без изменения файла изображения**. Статус показывает 🟣 **в приложении**.
- **Сохранить** записывает метаданные в сам файл изображения; статус становится 🟢 **просмотр**.
- **Сброс** (кнопка между кнопкой атрибутации и *Сохранить*) отменяет изменения, сохранённые только в приложении, и восстанавливает метаданные этого фото из файла. Сначала показывается подтверждение.
- **Автосохранение** записывает изменения в файл изображения автоматически после 1 секунды бездействия.

Индикатор состояния в заголовке панели показывает:

- 🟢 **просмотр** — файл и база данных совпадают (записано в файл)
- 🟡 **правка** — несохранённые правки в форме
- 🟣 **в приложении** — сохранено в приложении, ещё не записано в файл изображения
- 🔵 **пакет** — выбрано несколько файлов

Если файл фото изменён другой программой, Attributor обнаружит это при открытии фото, сравнив быстрый «отпечаток» содержимого (размер + время изменения + хеш содержимого).

## AI-атрибутация

Attributor может автоматически заполнять метаданные с помощью vision-модели. Провайдер выбирается в **Настройки → AI-атрибуция**; у каждого провайдера свои адрес, ключ и активная модель, поэтому переключаться между провайдерами можно свободно.

### Провайдеры

- **Ollama** запускает модели на этом компьютере. Если она не установлена, нажмите **Установить Ollama**, затем выберите vision-модель в поле **Скачать модель** и нажмите **Скачать**. Ollama запускается автоматически, когда она нужна. Облачные модели (с тегом `:cloud`) и удалённый **Базовый URL** отправляют фото на тот сервер.
- **Локальные серверы** — **llama.cpp** (`llama-server`), **LM Studio**, **Jan**, **vLLM** и **Unsloth** (Studio / Desktop) — подключаются через их OpenAI-совместимый API. Укажите в поле **Базовый URL** адрес сервера, включая `/v1` (изначально в поле стоит адрес сервера по умолчанию), убедитесь, что сервер предлагает vision-модель, и вставьте **API-ключ (необязательно)**, только если сервер его требует (Unsloth по умолчанию требует ключ). LM Studio запускается по требованию через CLI `lms`. vLLM не работает в Windows напрямую: укажите адрес WSL2, Docker или другой машины. Фото отправляется на сервер по базовому URL — обычно на этом компьютере.
- **OpenAI API** и **Claude API** — вставьте **API-ключ** (**Получить ключ** открывает страницу ключей провайдера).
- **ChatGPT** — нажмите **Продолжить с ChatGPT**, чтобы использовать план ChatGPT Plus или Pro через *Sign in with ChatGPT* от OpenAI; страница входа откроется в браузере. **Другой аккаунт** выполняет вход с другим аккаунтом или рабочим пространством ChatGPT. Запросы расходуют лимиты плана: **Управление лимитами** открывает страницу, где их можно посмотреть и ограничить. **Выйти** отменяет вход.
- Ollama получает исходный файл фото. Все остальные провайдеры получают JPEG-копию, уменьшенную до 1568 px; облачным провайдерам (OpenAI API, ChatGPT, Claude API) эта копия отправляется на анализ.
- API-ключи хранятся в хранилище учётных данных операционной системы, а не в файле настроек; вход в ChatGPT хранится в файле, зашифрованном ключом из этого хранилища.
- **Статус** показывает, готов ли провайдер (**Проверить** проверяет снова). Выберите или введите модель в поле **Активная модель**; **Обновить** заново загружает список моделей провайдера. **Заголовок формата ответа** ставится перед JSON-схемой, которая добавляется в конец каждого промпта, а **Формат JSON-ответа** — сама эта схема (только для отладки).

### Атрибутация фото

- Нажмите кнопку атрибутации в нижней части панели «Управление» — на ней написано имя активного провайдера, например *LM Studio*. Она анализирует открытое фото и заполняет «Заголовок», «Описание», «Ключевые слова», «Категории» и флаги атрибуции (Редакционное / Контент 18+ / Иллюстрация): заголовок, описание, категории и флаги заменяются, а предложенные ключевые слова добавляются к уже имеющимся.
- Кнопка доступна, когда в поле **Активная модель** выбрана модель и провайдер настроен: Ollama установлена, для OpenAI API или Claude API сохранён API-ключ, для ChatGPT выполнен вход. К локальным серверам приложение обращается при нажатии кнопки.
- Во время работы модели показывается блокирующий прогресс-бар с кнопкой **Отмена**; **Отмена** прерывает запрос.
- В **пакетном режиме** кнопка обрабатывает каждое выбранное фото по очереди. Фото, на котором произошла ошибка, пропускается, и пакет продолжается; **Отмена** останавливает пакет, а уже обработанные фото сохраняют результаты.
- Результаты сохраняются в базу данных приложения (статус 🟣 **в приложении**), а не в файлы. Проверьте их и нажмите **Сохранить** (в пакетном режиме — **Сохранить N файлов**), чтобы записать их в файлы.

### Профили моделей

В **Настройки → Профили моделей** задаются промпт, режим размышления и параметры запуска для атрибутации. У каждого профиля есть **Провайдер** и **Идентификатор модели**.

- Используется самый точный профиль: профиль активного провайдера для активной модели, профиль **Base (все провайдеры)** для этой модели, профиль провайдера с идентификатором модели `base` (запасной для любой модели без своего профиля), затем профиль `base` у Base. Если подходящего профиля нет или его промпт пуст, используется встроенный промпт для стоковых метаданных.
- Значения поля **Режим размышления** и поле **Параметры запуска (JSON)** зависят от провайдера профиля: диалог предлагает значения размышления этого провайдера и описывает, какие параметры запуска он принимает. При смене провайдера значение размышления, которого у него нет, сбрасывается. Параметры запуска профиля Base передаются как есть тому провайдеру, который выполняет запрос.
- **Время удержания** — настройка Ollama: поле есть у профилей Ollama и Base и используется, только когда запрос выполняет Ollama.
- **Создать** добавляет профиль; **Изменить** и **Удалить** изменяют или удаляют его. **Дублировать** открывает копию профиля как новый профиль с номером в имени (*Base* → *Base 2*); сохраните её, выбрав другого провайдера или идентификатор модели: для каждой пары провайдера и идентификатора модели может быть только один профиль. Чтобы изменить порядок списка, перетащите профиль за значок слева от имени.
- **Сбросить по умолчанию** заменяет список профилями по умолчанию: **Base**, **Base Ollama**, **Qwen2.5 VL 3b** и **Gemma4 Cloud**.

## Ключевые слова

### Добавление ключевых слов

- Введите ключевое слово в поле ввода и нажмите **Enter**.
- Введите несколько ключевых слов, разделённых **`, `** (запятая-пробел), чтобы добавить их все сразу.
- Выберите вариант из **выпадающего списка автодополнения**, который появляется по мере ввода (нечёткий поиск по более чем 1 000 стоковых терминов).
- Нажмите кнопку-значок **Стоковые ключевые слова** (рядом с полем ввода), чтобы открыть всплывающее окно с предопределёнными тегами по категориям; щёлкните любой тег, чтобы добавить его.

### Управление ключевыми словами

- **Перетаскивайте** чипы, чтобы изменить их порядок.
- Щёлкните **×** на чипе, чтобы удалить его.
- **Копировать** — копирует все ключевые слова в буфер обмена в виде списка, разделённого запятыми.
- **Вставить** — разбирает текст из буфера обмена и добавляет все найденные ключевые слова.

## Пакетный режим

Выберите **два или более файла** на панели «Иерархия» (с помощью `Shift`+щелчок или `Ctrl`+щелчок), чтобы войти в пакетный режим. Панель «Управление» переключается в режим редактирования нескольких файлов.

### Как работает пакетное редактирование

- **Заголовок / Описание / Категории** — у каждого поля есть флажок. Установите его, чтобы применить значение ко всем выбранным файлам при сохранении.
- Если у файлов уже есть разные значения для поля, в подсказке отображается **(разные значения)**, и флажок по умолчанию снят.
- **Ключевые слова** — показывается объединённый набор ключевых слов всех файлов:
  - **Сплошной чип** — ключевое слово присутствует во **всех** выбранных файлах.
  - **Пунктирный серый чип** — ключевое слово присутствует только в **некоторых** файлах. Перед ним появляется закрашенный кружок ● — щёлкните по кружку, чтобы распространить ключевое слово на все файлы.
- Щёлкните **×** на любом чипе, чтобы удалить это ключевое слово из всех файлов при сохранении.
- Перетаскивайте чипы, чтобы изменить их порядок.
- **Копировать** — копирует только общие (сплошные) ключевые слова.
- **Вставить** — добавляет ключевые слова во все выбранные файлы.

### Предпросмотр в пакетном режиме

На панели «Просмотр» отображается **последний выбранный файл**. Чтобы просмотреть конкретный файл из вашего выбора, не изменяя его, удерживайте **Alt** и щёлкните файл на панели «Иерархия».

### Сохранение пакетных изменений

Нажмите **Сохранить N файлов**, чтобы применить все изменения. Каждый файл обновляется по отдельности: перезаписываются только отмеченные поля; неотмеченные поля сохраняют свои исходные значения.

## Экспорт в CSV

Экспортируйте метаданные, сохранённые в приложении, в таблицы CSV — по одному файлу на фотосток — готовые к загрузке на площадки. Данные берутся из хранилища метаданных приложения, а не считываются заново из файлов, поэтому сначала просмотрите и сохраните фотографии.

### Настройка пресетов стоков

Attributor поставляется с готовыми пресетами для **Shutterstock**, **iStock**, **Adobe Stock** и **Envato**. Откройте **Файл → Настройки → Экспорт CSV**, чтобы использовать их как есть, изменить или создать свои. Каждый пресет содержит:

- **Название** — подпись, отображаемая в настройках.
- **Идентификатор стока** — используется как имя CSV-файла (`<идентификатор>.csv`); должен быть уникальным и допустимым как имя файла.
- **Разделитель столбцов** — запятая, точка с запятой или табуляция (по умолчанию запятая).
- **Поля** — упорядоченный список столбцов. Для каждого поля задайте заголовок **столбца CSV** и **значение**, которое в него попадает: нет (константа — **значение по умолчанию**), имя файла, заголовок, описание, ключевые слова, категория, файл релиза либо флаги «редакционное» / «контент 18+» / «иллюстрация» (с форматом **yes/no** или **true/false**). Меняйте порядок полей стрелками вверх/вниз. В пресете должно быть хотя бы одно поле.

### Запуск экспорта

Выберите **Файл → Экспорт в CSV** и укажите **папку назначения**. Приложение запишет туда по одному `<идентификатор>.csv` на каждый пресет (перезаписывая одноимённые файлы). Область экспорта — текущее выделение, а если ничего не выбрано — все фотографии в текущей папке, без вложенных под-папок. Фотографии без сохранённых в приложении метаданных пропускаются; в итоговом сообщении указывается, сколько файлов записано, сколько фото экспортировано и сколько пропущено.

## ИИ-ассистенты (MCP)

В Attributor встроен MCP-сервер (Model Context Protocol), поэтому ИИ-ассистенты — **Claude Desktop**, **Claude Code** и **ChatGPT / Codex** — могут работать с вашими фотографиями. Пока они работают, Attributor должен оставаться открытым.

### Настройка

1. Откройте **Настройки → MCP** и включите **Включить MCP-сервер**. В статусе показывается адрес, по умолчанию `http://127.0.0.1:47821/mcp`.
2. В разделе **Клиенты** нажмите **Установить** рядом с нужным ассистентом и перезапустите его:
   - **Claude Desktop** запускает Attributor как локальный мост (`attributor --mcp`). Полностью закройте Claude, в том числе из трея, и запустите снова.
   - **Claude Code** подключается по HTTP с токеном доступа во всех ваших проектах. Начните новую сессию или выполните `/mcp`, чтобы переподключиться.
   - **ChatGPT / Codex** — Codex CLI, его расширение для IDE и приложение ChatGPT для компьютера используют один файл настроек. После установки перезапустите их; в приложении ChatGPT инструменты доступны во вкладках **Codex** и **Work**. ChatGPT в браузере не может подключиться к программам на вашем компьютере.
3. **Обновить** перезаписывает устаревшую запись, **Удалить** убирает запись Attributor, **Показать файл** открывает папку с файлом настроек клиента, а **Копировать конфиг** копирует запись для ручной настройки клиента. Остальные серверы и настройки в этих файлах сохраняются, а предыдущая версия каждого файла остаётся рядом с ним как `.attributor-backup`.

### Что могут ассистенты

- Видеть, что открыто: папку, фото в редакторе, выделение, а также AI-провайдера и модель.
- Открывать папку, получать список её изображений и выделять изображения, чтобы вы их увидели: одно фото открывается в редакторе, несколько включают пакетный режим.
- Читать метаданные любого фото и смотреть маленькие или большие превью.
- Изменять поля, которые предлагает редактор, для одного фото или сразу для многих. Изменения хранятся в базе данных приложения (🟣 **в приложении**), пока ассистент их не сохранит; сохранение записывает их в файлы точно так же, как кнопка **Сохранить**, после тех же проверок (нужны заголовок, описание и хотя бы одно ключевое слово) и может переименовать один файл.
- Возвращать фото к метаданным из файлов и разрешать конфликты «файл изменён вне приложения».
- Запускать AI-атрибуцию с провайдером, моделью и профилем, заданными в Attributor: новые ключевые слова добавляются, остальные поля заменяются, а результаты остаются в приложении до сохранения. Долгие сохранения и атрибуции выполняются как задания, за которыми ассистент может следить и которые может отменить.
- Читать и менять настройки. Настройки нейросетей (провайдер, адреса, модели, профили моделей, формат ответа) меняются, только если включено **Разрешить менять настройки нейросетей**. Настройки MCP, API-ключи и вход в ChatGPT ассистентам недоступны никогда.

Когда ассистент меняет фото, открытое в редакторе, форма сразу показывает изменение; то, что вы ввели, но не сохранили, сначала сохраняется в базе данных приложения.

### Безопасность и журнал

- Сервер принимает подключения только с этого компьютера и только с **токеном доступа**; запросы с веб-страниц отклоняются.
- **Новый токен** заменяет токен. Установленные записи Claude Code и ChatGPT / Codex обновляются автоматически, а Claude Desktop читает токен сам; клиентам, настроенным вручную, нужно передать новый токен. При смене порта установленные записи тоже обновляются.
- В **Последних вызовах** показаны недавние вызовы инструментов с клиентом, длительностью и ошибкой, если она была.

## Система докинга

В Attributor есть три панели, которые можно свободно перемещать:

| Панель | Положение по умолчанию | Назначение |
|-------|-----------------|---------|
| **Управление** | Слева | Форма редактирования метаданных |
| **Просмотр** | По центру | Предпросмотр изображения |
| **Иерархия** | Справа | Дерево файлов / браузер |

### Изменение размера панелей

Перетащите разделитель между любыми двумя панелями, чтобы изменить их размер. Раскладка сохраняется автоматически.

### Закрытие и восстановление панелей

Щёлкните **×** в строке заголовка панели, чтобы закрыть её. Восстановите её через **Окна → Показать панель управления / Показать иерархию** в строке меню. Восстановленные панели возвращаются на своё последнее место.

### Перестановка панелей

Перетащите строку заголовка панели и отпустите её на **зоне сброса** (подсвеченные края) другой панели, чтобы разделить пространство и разместить её в любом месте раскладки.

## Режимы отображения панели «Иерархия»

Используйте панель инструментов в панели «Иерархия», чтобы переключать способ отображения файлов. Выбранные режим отображения и направление раскладки запоминаются между запусками.

### Режимы отображения

| Значок | Режим | Описание |
|------|------|-------------|
| ☰ | **Таблица** | Компактный список с именами файлов и деревом папок. |
| ▤ | **Содержимое** | Строка с миниатюрой и именем файла. |
| ⊞ | **Значки** | Сетка крупных миниатюр. |

### Направление раскладки (режимы «Содержимое» и «Значки»)

| Значок | Направление | Поведение |
|------|-----------|-----------|
| — | **Вертикально** | Элементы располагаются сверху вниз; каждое изображение занимает всю ширину панели. |
| ǀ | **Горизонтально** | Элементы выстраиваются слева направо в одну прокручиваемую строку; каждое изображение занимает всю высоту панели. Прокручивайте колёсиком мыши. |

## Сочетания клавиш

### Навигация по файлам

| Клавиша | Действие |
|-----|--------|
| `↑` / `↓` | Переместить выделение вверх / вниз в списке файлов |
| `Shift` + `↑` / `↓` | Расширить диапазон выделения |
| `Shift` + щелчок | Выбрать диапазон файлов |
| `Ctrl` + щелчок | Добавить / убрать отдельный файл из выделения |
| `Alt` + щелчок | Просмотреть выбранный файл на панели «Просмотр» (только в пакетном режиме, выделение не меняется) |

### Редактирование метаданных

| Клавиша / Ввод | Действие |
|-------------|--------|
| `Enter` | Добавить введённое ключевое слово |
| `, ` (запятая-пробел) | Добавить предшествующий текст как ключевое слово и продолжить ввод |
| `Esc` | Закрыть подсказки автодополнения / закрыть диалоги |
| `↑` / `↓` в подсказках | Перемещаться по списку автодополнения |

### Контекстное меню (текстовые поля)

Щёлкните правой кнопкой мыши по любому полю ввода или текстовой области, чтобы открыть контекстное меню:

| Пункт | Сочетание | Действие |
|------|----------|--------|
| **Копировать** | `Ctrl+C` | Скопировать выделенный текст в буфер обмена |
| **Вставить** | `Ctrl+V` | Вставить текст из буфера обмена в позицию курсора |

## Настройки

Откройте **Файл → Настройки** (или нажмите `Ctrl+,`).

| Раздел | Что можно изменить |
|--------|--------------------|
| **Общие** | Язык интерфейса; чтение вложенных папок. |
| **Редактор** | Автосохранение и его задержка. |
| **Внешний вид** | Тема — **Системная / Светлая / Тёмная** — и размер шрифта интерфейса. |
| **Кэширование** | Параметры кэширования фото и миниатюр. |
| **AI-атрибуция** | AI-провайдер и подключение к нему: статус, базовый URL, API-ключ или вход в ChatGPT, активная модель (а для Ollama — установка и скачивание моделей), заголовок формата ответа и формат JSON-ответа. |
| **Профили моделей** | Профили атрибуции для каждого провайдера и модели (промпт, режим размышления, параметры запуска, а для Ollama — время удержания); профили **Base (все провайдеры)** действуют для всех провайдеров. Создание, дублирование, изменение, удаление и порядок перетаскиванием. |
| **Экспорт CSV** | Пресеты CSV для каждого стока: название, идентификатор, разделитель столбцов и упорядоченный список полей. |
| **MCP** | MCP-сервер для ИИ-ассистентов: включение, адрес и порт, токен доступа, разрешение менять настройки нейросетей, установка в Claude Desktop, Claude Code и ChatGPT / Codex в один клик и последние вызовы. |
| **Горячие клавиши** | Просмотр и переназначение сочетаний клавиш, включая стрелки навигации по файлам. |

## Советы

- **Переименование при сохранении** — изменение поля «Имя файла» переименовывает сам файл при сохранении. Панель и дерево файлов обновляются автоматически.
- **Наблюдение за файлами** — если файлы перемещаются или удаляются извне, пока Attributor открыт, дерево обновляется автоматически, и появляется уведомление, если текущий открытый файл исчез.
- **Автосохранение + пакет** — в пакетном режиме автосохранение отключено, чтобы предотвратить случайную перезапись. Используйте кнопку **Сохранить N файлов** явно.
